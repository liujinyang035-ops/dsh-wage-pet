# dsh-wage-pet

桌宠式工资计程表。一枚有表情的小铜钱停在窗口角落，按你的薪资和工作时间每秒往上加钱；下班后它会眯起眼睛、头顶冒出 `z`。

## 安装

```sh
dsh plugin --profile desktop add dsh-wage-pet
```

装完重启 DSH，桌宠出现在右下角。桌面客户端与 Web 端都适用。

## 功能

- **计薪方式** — 月薪、日薪、时薪三选一，另外两项自动折算并显示在设置页。
- **工作制** — 双休、单休、大小周（按 ISO 周自动交替），或自定义每周天数。
- **实时累计** — 上班期间逐秒累加，午休暂停，下班停在当天目标值，休息日归零。
- **桌宠状态** — 工作时铜钱睁眼，计数期间眨眼更快；下班或休息时眯眼并浮出一个 `z`。
- **拖动与折叠** — 按住铜钱可拖到任意位置，位置会被记住；点一下折叠成只显示金额的小胶囊。
- **设置** — 金额、工作制、上下班时间、午休起点与时长。改动先进入草稿，点「保存」才生效，「取消」丢弃。

## 说明

- 配色取自宿主主题令牌，明暗主题自动跟随；只有铜钱本体使用固定的黄铜色。
- 支持跨天夜班，也支持把班次切成两段的午休。
- 配置存在 `localStorage` 的 `dsh-wage-pet:cfg:v1`，窗口位置存在 `dsh-wage-pet:pos:v1`。
- 修改薪资后，当天已累计的金额会按新时薪重新推算，所以这个数字的含义是「按现在这份薪资，到今天此刻赚了多少」。
